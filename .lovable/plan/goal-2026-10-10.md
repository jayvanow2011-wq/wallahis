## Goal
Deliver a corrected HidenHost server bundle that runs the WebSocket relay and isolated build worker, installs its Rust cross-compilation toolchain without requiring root access, uses the new shared keys, and is ready to download and publish.

## Changes
- Harden `server.js` startup and child-process handling while preserving one active agent connection per device and viewer deduplication.
- Repair `build-worker.js` toolchain setup so Rust and the Windows linker are installed in the service account’s home directory, PATH and linker variables are set for builds, setup failures stop polling clearly, and temporary build folders are always removed.
- Align the relay URL, port, build API URL, and secret names across the server configuration, worker, generated agent configuration, and app endpoint.
- Update the existing Lovable Cloud secrets through the secure secret form; keep downloadable templates safe rather than exposing key values.
- Add a non-root setup script and refresh deployment instructions.
- Validate JavaScript syntax, exercise startup/tool detection without compiling a full agent, create and inspect a clean ZIP in Files, then publish the app.

## Technical details
- Runtime remains Node.js with the build worker isolated via `child_process.fork()`.
- Linux cross-compilation prefers an existing MinGW linker; without root access it downloads a pinned portable LLVM-MinGW release and configures Cargo to use it.
- Build API calls continue using `X-Buildserver-Key`; relay connections continue using `HIDEN_AUTH_KEY`.
- The server binds to `0.0.0.0:24578`; public clients use `wss://umad.servemc.net`.
